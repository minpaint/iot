# Сборка ИОТ по макету

## Когда использовать
- Просят разработать, собрать, пересобрать или обновить инструкцию по охране труда (ИОТ) по макету — одну или несколько сразу (пакет).
- Источник специфических требований — один или несколько (режимы можно сочетать):
  - **Режим 1.** Требования, которые даёт пользователь (текстом или файлом).
  - **Режим 2.** Паспорт, руководство по эксплуатации, техническая документация на оборудование/инструмент.
  - **Режим 3.** Старая ИОТ (одна или несколько) для пересборки по макету.

## Где лежит макет (единственный эталон)
- Google Диск, файл «Макет_ИОТ.docx», ID `10Mq2FzKhYCCspJqtNExFDQT7C90UC4FI`.
- На компьютере: `G:\Мой диск\!Информация\!!!База инструкций по ОТ\Макет\Макет_ИОТ.docx`. Рядом лежат этот навык (`SKILL.md`) и файл «Реквизиты» (см. Шаг 1).
- **Макет никогда не изменять.** Всегда работать с копией.
  - Сессия с Google Диском: скачать файл по ID (download_file_content → base64 → .docx).
  - Сессия, связанная с компьютером: скопировать файл из папки «Макет» (stage).
  - Claude в Word: пользователь открывает копию макета; работать в открытом документе. Если открыт сам «Макет_ИОТ.docx» — остановиться и попросить открыть копию.
- Если макет недоступен ни одним способом — сказать об этом и попросить приложить файл. Не собирать по памяти.
- Результат: новый файл «ИОТ_[профессия или вид работ].docx» (вне папки «Макет»); в Word — сохранить копию под этим именем.

## Устройство макета
- Шапка: два альтернативных блока утверждения `[[ЕСЛИ: профсоюза нет]]` / `[[ЕСЛИ: есть профсоюз]]` (второй — таблица СОГЛАСОВАНО профкома + УТВЕРЖДЕНО). Скрытые пустые абзацы в шапке не трогать.
- Заголовок:
  `Инструкция / по охране труда / [[ЕСЛИ: инструкция по профессии]] для [[ПРОФЕССИЯ: р.п.]] [[КОНЕЦ]] / [[ЕСЛИ: инструкция по виду работ]] при выполнении [[ВИД РАБОТ]] [[КОНЕЦ]] / ИОТ № [[НОМЕР ИОТ]]`.
- Колонтитул (таблица): `[[ОРГАНИЗАЦИЯ]] | ИОТ № [[НОМЕР ИОТ]] | Стр. X из Y` (поля PAGE/NUMPAGES не трогать).
- Главы 1–5 + `[[ЕСЛИ: есть иные главы]] Глава 6 (ИНЫЕ ГЛАВЫ…) … [[КОНЕЦ]]`. Заголовок главы — один абзац ConsPlusNormal с разрывом строки между «Глава N» и названием.
- В главах 2–5 — врезки `[[СПРАВКА: “33…36. В главе … отражаются: …”]]` (выдержки из Инструкции № 176).
- Пункты — сквозная автонумерация Word (один список). Перечисления внутри пункта — отдельные абзацы без номера и маркера.
- В конце — таблица СОГЛАСОВАНО: `[[ДОЛЖНОСТЬ: согласующий]]`, `[[ФИО СОГЛАСУЮЩЕГО]]`, `[[ДОЛЖНОСТЬ: разработчик]]`, `[[ФИО РАЗРАБОТЧИКА]]`.
- Слово «работающий» стоит на месте профессии во всех падежах.
- Шрифт — Times New Roman 12; стили ConsNormal / ConsPlusNormal; поля: левое 2 см, остальные 1 см (уже заданы в макете).

### Три типа маркеров-пометок
| Маркер | Смысл | Что делать |
|---|---|---|
| `[[ПОЯСНЕНИЕ: …]]` | инструкция разработчику (3 места: гл. 1 п. 1, примеры гл. 3, гл. 6) | использовать при заполнении, **удалить всегда**; многоабзацное пояснение (примеры гл. 3) удалять целиком, вместе со всеми абзацами |
| `[[ПОЛЕ: имя \| обяз \| необяз \| подсказка]]` | заглушка под данные (14 полей: 9 обязательных, 5 необязательных) | заполнить данными и удалить маркер. Не заполнено: **обязательное** — оставить в тексте жёлтой меткой «▢ имя» и внести в лист замечаний; **необязательное** — удалить молча |
| `[[СПРАВКА: …]]` | выдержки пп. 33–36 Инструкции № 176 | сверить с ними главу, затем **удалить всегда** вместе с врезкой-таблицей |

Поля: ограничения по полу (необяз); вредные и опасные факторы; СИЗ по типовым нормам (таблица); СИЗ для защиты (по виду работ); дополнительные требования глав 1, 2, 4, 5 (необяз); требования при выполнении работы; исходные материалы; транспорт, тара, грузоподъёмные механизмы; отклонения от режима и их устранение; взрывы, пожары, аварийные ситуации; остановка, разборка, очистка и смазка (всё остальное — обязательные).

**Служебные пометки** (проверить перечень факторов, нет данных, риск без меры, источник документа) в документ **не попадают** — только в отчёт и лист замечаний.

### Остальные маркеры
| Маркер | Что делать |
|---|---|
| `[[ЕСЛИ: условие]] … [[КОНЕЦ]]` | условие выполняется — удалить только маркеры; нет — удалить всё между ними вместе с маркерами (блок может быть внутри абзаца, охватывать несколько абзацев или таблицу) |
| `[[ВАРИАНТ: фрагмент]]` (7 мест) | по смыслу профессии оставить фрагмент целиком, сократить до применимого или удалить; текст не переписывать, только вычёркивать неприменимое. Нет данных — оставить целиком (без маркера) и упомянуть в отчёте |
| `[[ПРОФЕССИЯ: р.п.]]` | профессия в родительном падеже («водителя погрузчика») |
| `[[ВИД РАБОТ]]` (3 места: заголовок, п. о допуске, п. о СИЗ) | одна и та же форма в родительном падеже, подходящая ко всем трём: «работ на высоте», «погрузочно-разгрузочных работ» |
| `[[НОМЕР ИОТ]]` (заголовок и колонтитул) | одно значение в оба места |
| `[[ОРГАНИЗАЦИЯ]]` | полное наименование с организационно-правовой формой |
| `[[ДОЛЖНОСТЬ: утверждающий]]`, `[[ФИО УТВЕРЖДАЮЩЕГО]]` (в обоих вариантах шапки) | должность и инициалы, фамилия |
| `[[ДОЛЖНОСТЬ: согласующий]]`, `[[ФИО СОГЛАСУЮЩЕГО]]`, `[[ДОЛЖНОСТЬ: разработчик]]`, `[[ФИО РАЗРАБОТЧИКА]]` | блок СОГЛАСОВАНО в конце |
| `[[ДОЛЖНОСТЬ: уполномоченное лицо, которое необходимо извещать]]` | должность лица (п. «обязан… немедленно извещать») |
| `[[ГРУППА ПО ЭБ: …]]` (п. о допуске, 2 варианта) | римская цифра после «не ниже» («III»), **без скобок** — в обоих вариантах: «не ниже III». Не положена — удалить вместе со словами «и имеющие группу по электробезопасности не ниже» / «имеющие соответствующую группу по электробезопасности» |

Условия `[[ЕСЛИ]]` в макете (20 пар): профсоюза нет / есть профсоюз; инструкция по профессии / инструкция по виду работ; при выполнении работ на ОПО или с ПОО; при выполнении работ с повышенной опасностью; есть коллективный договор; **работа по гражданско-правовому договору** (абзац о ГПД — только для «по виду работ»); сменный характер работы / работа не сменная; блок СИЗ по профессии (`[[ЕСЛИ: инструкция по профессии]]` вокруг таблицы СИЗ); есть иные главы.

## Шаг 1 — Диалог: собрать данные после запуска
Навык **сам спрашивает** данные сразу после запуска. Что уже сказано в сообщении — не переспрашивать. Если пользователь сказал «не спрашивай» — заполнить известное, остальное оставить по правилам полей.

**1.0. Реквизиты.** Найти файл «Реквизиты» рядом с макетом (`…\Макет\Реквизиты.txt`; на Диске — в той же папке). Если есть — прочитать и показать пользователю одной строкой («Организация: …, утверждающий: …, согласующий: …, разработчик: …. Те же?»). Файл хранит: организацию, утверждающего, согласующего, разработчика (должности и ФИО), должность лица для извещения, признак профсоюза, коллективный договор. Изменилось что-то — обновить файл (только по подтверждению). Файла нет — спросить в 1.2 и предложить создать.

**1.1. Карточки выбора** (AskUserQuestion, до 4 вопросов за раз; по умолчанию — первый вариант):
- Тип ИОТ: по профессии / по виду работ.
- Флаги: профсоюз (нет/есть); коллективный договор (нет/есть); ОПО/ПОО (нет/да); повышенная опасность (нет/да); сменная работа (да/нет).
- Работа по гражданско-правовому договору: **по умолчанию «нет»** (спрашивать только для «по виду работ»).
- Режим источника: требования пользователя / паспорт / старая ИОТ (можно несколько).

**1.2. Реквизиты — одним сообщением** (не по одному вопросу): профессия (им. и род. падеж) или вид работ (род.); номер ИОТ; группа по ЭБ (или «не положена»); организация; утверждающий, согласующий, разработчик (должность, ФИО); должность лица для извещения. Недостающее из файла «Реквизиты» — не спрашивать повторно.

**1.3. Пакет.** Если ИОТ несколько — попросить **список строк** (одна строка = одна ИОТ: профессия или вид работ; номер; при необходимости отличающиеся флаги/источники). Общие реквизиты спрашивать один раз на весь пакет. **Сначала собрать одну ИОТ и показать пользователю**, после его подтверждения собирать остальные тем же способом.

Файлы .doc не читаются — попросить .docx или PDF.
**Готово, когда:** известны тип, профессия/вид работ, все флаги, реквизиты и источники по каждой ИОТ пакета.

## Шаг 2 — Условия, маркеры, склонение
1. Обработать все `[[ЕСЛИ]] … [[КОНЕЦ]]`, кроме `[[ЕСЛИ: есть иные главы]]` — его решить на Шаге 5 (есть ли что-то для главы 6).
2. Заполнить маркеры подстановки (кроме `[[ПОЛЕ]]` — они на Шагах 3–5). Неизвестное необязательное — удалить, обязательное — жёлтая метка «▢ имя».
3. Склонение:
   - **По профессии:** «работающий» (ед. ч., любой падеж), обозначающий работника по этой ИОТ, заменить профессией в том же падеже с согласованием («работающему» → «водителю погрузчика», «его» и «он» — по смыслу). В п. 1: «по профессии «работающий»» → «по профессии «водитель погрузчика»», «(далее — работающий)» → «(далее — водитель погрузчика)». Обобщённое мн. ч. «работающих» («жизни или здоровью работающих и окружающих», «нахождение работающих…») не трогать.
   - **По виду работ:** «работающий» сохраняется.
4. `[[ВАРИАНТ]]` — обработать по таблице выше.
**Готово, когда:** нет `[[ЕСЛИ` (кроме главы 6) и `[[КОНЕЦ]]` без пары, известные маркеры заполнены, падежи согласованы.

## Шаг 3 — Глава 1: факторы, СИЗ, ссылки
- **Ограничения по полу** (`[[ПОЛЕ: ограничения по полу]]`): только если пользователь/источник их указал; иначе удалить молча.
- **Вредные и опасные факторы** (`[[ПОЛЕ: вредные и опасные факторы]]`): из старой ИОТ, если там есть перечень (дословно); иначе подобрать по ГОСТ 12.0.003 для профессии и внести в отчёт «проверить перечень факторов» (не в документ).
- **Карта рисков:** только общей фразой, как в макете («…представлен в карте идентификации опасностей, оценки рисков и определения мер управления по профессии и видам выполняемых работ»). Данные из Excel-карты не переносить.
- **Перечень инструкций** (п. «должен знать и исполнять»): оставить общую фразу «инструкции по видам выполняемых работ».
- **СИЗ (по профессии):** заполнить таблицу из 3 колонок — «Наименование средств индивидуальной защиты» | «Классификация (маркировка) СИЗ по защитным свойствам» | «Сроки носки в месяцах / Нормы выдачи (штук, пар) на год» — по типовым нормам бесплатного обеспечения работников СИЗ Минтруда и соцзащиты РБ для точной профессии (веб-поиск, ссылка на источник в отчёте). Лишние пустые строки удалить, недостающие добавить.
- **СИЗ (по виду работ):** таблица не заполняется (блок «по профессии» удалён условием); заполнить `[[ПОЛЕ: СИЗ для защиты (по виду работ)]]` — перечень «выдаются для защиты:».
- **СИЗ из паспорта (режим 2), которых нет в типовых нормах:** добавить в абзац «При необходимости… выдаются следующие СИЗ» и в пункт «Надеть средства индивидуальной защиты:» главы 2; в обоих местах выделить жёлтым и дописать «(из паспорта)». Жёлтым «(из паспорта)» помечаются **только** такие СИЗ.
- Пример-перечень СИЗ «глаз / слуха / дыхания» оставить только применимые строки.
- **Дополнительные требования глав 1, 2, 4, 5** (необяз): заполнить, если есть что добавить (требования, характерные для организации); иначе удалить молча.
**Готово, когда:** таблица СИЗ заполнена, перечень факторов есть, ссылка на карту — общей фразой.

## Шаг 4 — Извлечение специфических требований
### Режим 1 — требования пользователя
Распределить по главам 2–5 по смыслу; формулировки пользователя сохранять (кроме «Правил текста»).

### Режим 2 — паспорт / руководство по эксплуатации
1. Прочитать документ целиком (все страницы; при низком качестве скана — отметить это). При нескольких документах определить тип каждого оборудования (без марок и моделей), сгруппировать, сообщить группы. Неочевидный тип — классифицировать по функции («ручной электроинструмент») с пометкой в отчёте.
2. Извлечь всё, что относится к безопасности: предупреждения (ОПАСНО, ПРЕДУПРЕЖДЕНИЕ, ОСТОРОЖНО, DANGER, WARNING, CAUTION), СИЗ, запреты и ограничения, подготовка/пуск/остановка (если нарушение ведёт к травме или неконтролируемому движению), действия при аварии, требования к месту работ, освещению, вентиляции.
3. Фильтры:
   - **Технология vs безопасность:** только то, нарушение чего ведёт к травме, поражению током, пожару, поломке с разлётом частей. Критерий — техническая связь с вредом, а не слово «внимание».
   - **Стоп-лист:** прогрев и обкатка; интервалы и регламенты ТО; марки, типы, уровни жидкостей; пошаговые процедуры погрузки/выгрузки/обработки; консервация и длительное хранение; замена ламп, предохранителей, расходников — кроме аспекта, прямо ведущего к травме.
   - **Метки:** ПРИМЕЧАНИЕ / NOTE / УВЕДОМЛЕНИЕ / NOTICE не извлекать, если не продублировано под меткой опасности.
   - **Тест последствия:** только износ, ресурс, производительность, повреждение узла без разлёта/возгорания/тока/травмы → не включать.
   - **Остаточные риски** («Остаточные риски», «Residual risks», «Restrisiken»): каждый превратить в требование для главы 3 («риск отдачи» → «крепко держать инструмент двумя руками, не находиться в зоне возможного отскока»). Меры в документе нет — не сочинять: внести в отчёт «в исходном документе указан остаточный риск: …, мера не указана» и оставить соответствующее поле жёлтой меткой.
4. Несколько документов одного типа: без дублей; при разной строгости — более строгое; несопоставимые числа разных моделей — отсылка к эксплуатационной документации на конкретную модель.
5. Агрегация внутри главы и вида оборудования: безусловные запреты — один пункт «Не допускается:»; СИЗ — один пункт «Надеть средства индивидуальной защиты:». Запреты для конкретного аварийного сценария — отдельным пунктом.
6. Порядок в главах 2 и 3: инженерные меры → организационные → СИЗ → «Не допускается:». Глава 4 — хронологически: выключить → отсоединить/сбросить давление → осмотреть/очистить → убрать на хранение. Аварийные действия — в главу 5.
7. Перенос в профессиональный контекст: «не допускайте детей» → «не допускать на рабочее место посторонних лиц»; «храните в сухом месте» → «по окончании работы разместить инструмент в специально отведённом сухом месте хранения»; «обращаться в авторизованный сервис» → «ремонт осуществляется силами специализированного персонала». Нет эквивалента — не включать. Не включать «ознакомьтесь с настоящей инструкцией», марки, модели, производителей.
8. Только из документа; для главы без данных — запись в отчёт «в исходном документе информация отсутствует».
9. Язык: русский, точный перевод терминов; формы «Убедиться в том, что…», «Проверить…», «Надеть…», «Отключить…», «Не допускается…». Без «воды».
10. Реквизиты документа-источника («требования извлечены из технической документации изготовителя: [название и реквизиты]») — в отчёт, не в текст ИОТ.

### Режим 3 — старая ИОТ
1. Зафиксировать список документов (названия, профессии/виды работ).
2. Извлечь все требования безопасности из каждого документа, независимо от того, после каких слов они стоят.
3. Сравнить с макетом: совпадает — если смысл и содержание уже есть в макете, даже при иной формулировке; уникально — если в макете нет ни этого действия, ни запрета, ни операции. При сомнении — уникально.
4. Перенос **дословный**: не пересказывать; числа, единицы, термины сохранять. Разрешены только замены из «Правил текста».
5. Повторы из нескольких ИОТ — один раз, с пометкой в отчёте «(повтор из [название документа])».
6. Работать сразу в документе, без промежуточных списков в чате.
**Готово, когда:** каждое требование распределено: глава 2/3/4/5/6 или «совпадает с макетом».

## Шаг 5 — Вставка в главы
1. Специфические требования — в главы 2–5 **после общих пунктов макета** этой главы (подготовка → 2, выполнение → 3, окончание → 4, аварии → 5), в соответствующие `[[ПОЛЕ]]`. Не подходящее ни к одной главе — в главу 6, внутрь блока `[[ЕСЛИ: есть иные главы]]`, перед `[[КОНЕЦ]]`. Если в главу 6 ничего не попало — удалить блок целиком (с заголовком главы).
2. Для оборудования внутри главы — подзаголовок «При эксплуатации [тип оборудования]»: оформить как заголовок главы (жирный, по центру, без номера, не элемент списка), затем пункты.
3. Пункт — элемент той же автонумерации, что соседние пункты главы (без номеров, набранных вручную). Перечисление: заголовок пункта с двоеточием, далее каждый элемент — отдельный абзац без номера и маркера, со строчной буквы, через «;», последний — «.».
4. **Шаблон главнее.** Требование источника, которое противоречит макету или дублирует его пункт, всё равно вставить в соответствующее место, но целиком красным зачёркнутым (цвет FF0000, зачёркивание) — чтобы пользователь видел исключённое. Не подошедшее — в главу 6.
5. Примеры макета (лестницы и работа на высоте в гл. 3 и т.п.) оставить, только если подходят профессии/виду работ; иначе удалить целиком вместе со всеми абзацами примера.
6. Новые абзацы — стиль соседнего пункта, Times New Roman 12; не переносить курсив подсказок.
**Готово, когда:** все требования вставлены, нумерация сквозная без разрывов.

## Шаг 6 — Очистка и финальная проверка
1. **Обязательные поля глав 2–5 (пп. 33–36 Инструкции № 176).** Перед удалением `[[СПРАВКА]]` сверить каждую главу с врезкой. Обязательное `[[ПОЛЕ]]`, по которому нет данных (исходные материалы; транспорт, тара и грузоподъёмные механизмы; отклонения от режима; взрывы, пожары, аварийные ситуации; остановка, разборка, очистка, смазка; требования при выполнении работы; вредные и опасные факторы; СИЗ) — оставить жёлтой меткой «▢ имя» и внести в **лист замечаний**. Если элемент к профессии неприменим — удалить поле и указать это в отчёте.
2. Удалить все `[[ПОЯСНЕНИЕ]]` и `[[СПРАВКА]]` (врезки-таблицы целиком). Необязательные пустые `[[ПОЛЕ]]` удалить молча. Служебных пометок в документе не оставлять. Удалить пустые абзацы, пустые нумерованные пункты и лишние пробелы после удалений (двойные пробелы, пробел перед знаком препинания, пробел в начале/конце абзаца).
3. Проверить:
   - нет `[[ЕСЛИ`, `[[КОНЕЦ`, `[[ВАРИАНТ`, `[[ПОЯСНЕНИЕ`, `[[СПРАВКА`, `[[ПОЛЕ`; оставшиеся `[[…]]` — только незаполненные данные (подстановки) — перечислить их в чате;
   - нет «запрещается», «запрещено», «нельзя» (в значении «невозможно» — «невозможно»; в значении запрета — «не допускается»); нет «работник» (кроме «медицинских работников» и названия «типовые нормы бесплатного обеспечения работников СИЗ»), нет «наниматель» — в перенесённом тексте;
   - падежи профессии согласованы (по профессии), одна форма `[[ВИД РАБОТ]]` во всех местах (по виду работ);
   - группа по ЭБ — «не ниже III» без скобок;
   - ссылка на карту рисков — общей фразой;
   - нет марок, моделей, производителей, «дети», «ознакомиться с настоящей инструкцией»;
   - все общие пункты макета на месте; числа из источников сохранены;
   - перечисления без номеров и маркеров; красные зачёркнутые и жёлтые «(из паспорта)» на месте;
   - жёлтые метки «▢ имя» стоят только на обязательных полях без данных и все перечислены в листе замечаний;
   - номер ИОТ и организация в колонтитуле совпадают с заголовком.
4. Работа с файлом (не в Word): docx — ZIP; распаковать, перед поиском маркеров объединить разорванные runs (маркер может быть разбит на несколько runs; run с несколькими `w:t` разбить), править `word/document.xml` и `word/header*.xml`, упаковать, проверить валидность (validate.py с `--original`), отрендерить в PDF и просмотреть страницы. Следить, чтобы при разбиении runs текст не дублировался (сверить объём текста до/после).
**Готово, когда:** проверка пройдена; в чате — короткий отчёт: что заполнено, сколько требований вставлено по главам, сколько зачёркнуто красным, какие `[[ВАРИАНТ]]` оставлены целиком, **лист замечаний** (обязательные поля без данных, служебные пометки: перечень факторов, остаточные риски без меры, реквизиты источников), какие маркеры остались.

## Правила текста (всегда)
- «запрещается», «запрещено», «нельзя» → «не допускается» («нельзя» в значении «невозможно» → «невозможно»).
- В переносимом тексте: работник → работающий (кроме «медицинских работников»); наниматель → работодатель.
- Ссылка на СУОТ-документ — только общей фразой о карте идентификации опасностей.
- Перечисления — со строчной буквы, через «;», без номеров и маркеров.
- Шрифт — Times New Roman 12; стили макета ConsNormal / ConsPlusNormal.

## Пример
Вход: «ИОТ для водителя погрузчика, по профессии, профсоюз есть, коллективного договора нет, сменная работа, ОПО нет, паспорт погрузчика приложен».
Ход: навык находит «Реквизиты», показывает их одной строкой, карточками уточняет флаги (ГПД по умолчанию «нет»), одним сообщением запрашивает недостающее (номер ИОТ, группа по ЭБ, подписанты).
Выход: шапка с блоком профсоюза; заголовок «для водителя погрузчика»; «работающий» → «водитель погрузчика» в нужных падежах; удалены блоки «по виду работ», «работа не сменная», ОПО, коллективный договор, ГПД; `[[ВАРИАНТ]]` сокращены по смыслу; таблица СИЗ по типовым нормам + жёлтые «(из паспорта)»; в главах 2–5 после общих пунктов — «При эксплуатации погрузчика» и требования по иерархии мер; дубли с макетом — красным зачёркнутым; глава 6 удалена, если пуста; обязательные поля без данных — жёлтое «▢ имя»; отчёт и лист замечаний в чате.
